# TradeSim 交易模拟器

基于 Binance 真实历史行情的加密货币交易策略模拟器，使用 Next.js 16 + TypeScript + Tailwind CSS 构建。

## 已实现的模拟器

所有模拟器共用行情选择、手续费/杠杆设置、回测K线、收益曲线、指标对比和成交明细。

### 网格模拟器（`/grid`）

- 选择开始 / 结束日期、交易对（USDT 计价）、K线周期（自动或手动）
- 行情来自 Binance 公共接口：现货 K 线、U 本位永续合约 K 线、合约历史资金费率
- **现货模式**：对比「现货持有」与「现货网格」的收益曲线
- **合约模式**：可设置杠杆和维持保证金率，对比「合约买入持有」「做多网格」「做空网格」「中性网格」
- 手续费：网格挂单按 Maker、初始建仓/持有按 Taker 计费，现货与合约费率分开设置
- 资金费率：按真实历史费率与结算时刻计入（多头费率为正时支付，空头收取）
- 强平：权益低于维持保证金时强平，剩余保证金视为全部损失
- 回测K线图（TradingView Lightweight Charts）显示网格线与成交标记，与收益曲线时间轴联动
- TradingView 官方嵌入图表（嵌入版不支持锁定任意历史区间，仅设置回看范围）
- 策略指标对比表：收益率、年化、最大回撤、网格利润、持仓盈亏、手续费、资金费、爆仓信息
- 成交明细分页表

### 定投模拟器（`/dca`）

- 现货，定投周期：每天 / 每周 / 每两周 / 每月（按月时月末自动取当月最后一天）
- 对比「一次性买入」「定期定额」「价值平均」，三者使用相同的计划总资金，未投入部分按现金计入权益
- 价值平均：每期让持仓市值增加一期金额，下跌多买、上涨少买或不买，不卖出，单期金额有上限
- 指标：投入本金、剩余现金、买入次数、持仓均价、本金收益率

### 马丁格尔模拟器（`/martingale`）

- 现货：对比「现货持有」与「马丁格尔」；合约：对比「合约买入持有」「马丁格尔做多」「马丁格尔做空」
- 参数：投入资金、加仓间隔、间隔倍数、加仓倍数、最大加仓次数、止盈比例、止损比例
- 首单金额由投入资金和加仓倍数反推，保证加满仓时正好用完资金（合约为投入 × 杠杆）；侧栏实时预览加仓阶梯
- 首单与止损为市价单（Taker），加仓与止盈为挂单（Maker）；止盈后立即以当前价开始下一轮，止损后停止
- 指标：已实现利润、止盈轮数、单轮最多加仓次数、止损次数、持仓盈亏

## 快速开始

```bash
npm install
npm run dev
```

打开 http://localhost:3000 。

如果本机需要代理才能访问 Binance，启动时设置代理环境变量（服务端会自动使用）：

```bash
HTTPS_PROXY=http://127.0.0.1:7890 npm run dev
```

可选环境变量：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `BINANCE_SPOT_BASE_URL` | `https://api.binance.com` | 现货接口域名，失败时自动回退到 `data-api.binance.vision` |
| `BINANCE_FUTURES_BASE_URL` | `https://fapi.binance.com` | U 本位合约接口域名 |
| `HTTPS_PROXY` / `HTTP_PROXY` | — | 访问 Binance 使用的代理 |
| `BINANCE_FUTURES_SOURCE` | — | 设为 `archive` 时合约数据强制使用历史归档 |
| `BINANCE_ARCHIVE_BASE_URL` | `https://data.binance.vision` | 历史归档域名 |

### 合约接口被地区限制（HTTP 451）

`fapi.binance.com` 在部分地区不可用，且没有公共镜像。遇到 451/403 或无法连接时，服务端会自动改用 Binance 官方历史归档 `data.binance.vision`（10 分钟后再尝试接口）：

- K 线：已结束的月份用月文件，当月用日文件，**数据最新到昨天（UTC）**
- 资金费率：归档只有月文件，尚未归档的最近月份按 1 分钟溢价指数和 Binance 资金费率公式估算（与真实值的误差约为每次 0.0001%～0.002%），页面会标明估算起点
- 合约交易对列表：用现货 USDT 交易对列表近似

需要今天的实时数据时，请配置能访问 Binance 的 `HTTPS_PROXY`。

## 回测模型与假设

- **记账**：`权益 = 现金 + 持仓数量 × 价格`，现货与 U 本位线性合约通用
- **K线内路径**：阳线按 开→低→高→收，阴线按 开→高→低→收 撮合，途经的挂单依次成交；周期越小越接近真实
- **网格构建**：等差 / 等比，每格数量相等。以回测起点开盘价为界：
  - 做多网格 / 现货网格：价格上方的格子初始市价买入，挂卖单；下方格子挂买单
  - 做空网格：价格下方的格子初始市价开空，挂买单平空；上方格子挂卖单开空
  - 中性网格：不建初始仓，上方格子开空、下方格子开多
  - 离当前价最近的一档不挂单（与 Binance 一致）
- **资金占用**：合约名义价值 = 投入 × 杠杆，按各格挂单价（已持仓格按开盘价）反推每格数量
- **价格越界**：超出网格区间后不再有挂单成交，持仓随价格浮动（暂未实现止盈止损）
- **强平**：在每段路径端点检查 `权益 ≤ |持仓| × 价格 × 维持保证金率`，使用成交价近似标记价格
- **资金费**：在结算时刻按该时刻前的持仓与接口返回的标记价格（缺失时用K线开盘价）结算
